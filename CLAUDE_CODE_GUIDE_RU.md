# Как работать с Claude Code — Инструкция для Антона

## Что такое Claude Code

Claude Code — это CLI-инструмент (командная строка), который позволяет Claude работать с файлами на твоём компьютере напрямую. Ты открываешь терминал, запускаешь Claude Code в папке проекта, описываешь задачу — и Claude создаёт/редактирует файлы.

## Установка

### 1. Убедись, что у тебя установлен Node.js
```bash
node --version
# Нужен v18+. Если нет — скачай с https://nodejs.org
```

### 2. Установи Claude Code
```bash
npm install -g @anthropic-ai/claude-code
```

### 3. Проверь установку
```bash
claude --version
```

## Как использовать для этого проекта

### Шаг 1: Открой терминал и перейди в папку проекта
```bash
cd путь/к/cm-analytics-prototype
```

Это папка, где лежат файлы CLAUDE.md, PROTOTYPE_SPEC.md и т.д.

### Шаг 2: Запусти Claude Code
```bash
claude
```

Claude Code автоматически прочитает `CLAUDE.md` из текущей папки — это его "инструкция". Он будет знать про проект, дизайн, и что нужно делать.

### Шаг 3: Дай задачу

Просто напиши в чат:

```
Прочитай PROTOTYPE_SPEC.md и создай index.html — полный интерактивный прототип аналитики Code Maestro. Следуй спецификации точно. Все данные захардкожены, один HTML файл.
```

Claude Code прочитает спецификацию и начнёт создавать файл. Он будет показывать тебе, что делает, и спрашивать разрешение на запись файлов.

### Шаг 4: Итерации

Когда index.html создан, открой его в браузере и посмотри результат. Если нужно что-то исправить:

```
Открой index.html в браузере — вот что нужно поправить:
- Воронка на дашборде слишком мелкая, сделай крупнее
- Цвет заголовков слишком тёмный на тёмном фоне
- Добавь анимацию при переключении табов
```

Claude Code отредактирует файл прямо на месте.

## Полезные команды в Claude Code

| Действие | Что написать |
|----------|-------------|
| Создать файл | «Создай index.html с содержимым...» |
| Редактировать | «В index.html измени цвет заголовка на #FCBC16» |
| Прочитать файл | «Прочитай PROTOTYPE_SPEC.md» |
| Запустить в браузере | «Запусти локальный сервер для index.html» |
| Посмотреть структуру | «Покажи содержимое папки» |

## Советы

1. **Будь конкретным** — вместо «сделай красивее» пиши «увеличь font-size заголовков до 24px и добавь отступ 20px сверху»
2. **Одна задача за раз** — не проси 10 вещей сразу, лучше по одной
3. **Давай контекст** — «на табе Dashboard воронка обрезается справа» лучше, чем «воронка сломана»
4. **Используй /clear** — если разговор стал слишком длинным, начни новый чат (CLAUDE.md загрузится снова)

## Структура проекта

```
cm-analytics-prototype/
├── CLAUDE.md              ← Инструкции для Claude Code (читает автоматически)
├── PROTOTYPE_SPEC.md      ← Детальная спецификация прототипа
├── DEMO_GUIDE.md          ← Руководство по демонстрации (для тебя)
├── CLAUDE_CODE_GUIDE_RU.md ← Этот файл
├── reference/
│   └── research_summary.md ← Краткое саммари исследования рынка
└── index.html             ← ⬅ ЭТОТ ФАЙЛ СОЗДАСТ CLAUDE CODE
```

## Примерный сценарий работы

```
1. $ cd cm-analytics-prototype
2. $ claude
3. > Прочитай PROTOTYPE_SPEC.md и создай index.html
4. (Claude Code создаёт файл ~5-10 минут)
5. Открываешь index.html в Chrome
6. > Таб Insights — insight cards слишком узкие, сделай шире на 30%
7. > На Hypothesis Lab добавь прогресс-бары к экспериментам
8. > Сделай переход между табами более плавным, 300ms ease
9. (Итерируешь до идеального результата)
```

## Troubleshooting

**Если Claude Code не видит CLAUDE.md:**
Убедись, что ты запускаешь `claude` из правильной папки (где лежит CLAUDE.md).

**Если файл получился слишком длинный и Claude Code не может его дописать:**
Попроси: «Продолжи создание index.html с того места, где остановился»

**Если Charts не отображаются:**
Убедись, что у тебя есть интернет — Chart.js загружается с CDN.
