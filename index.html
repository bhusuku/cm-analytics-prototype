CRITICAL

Tutorial Drop-off (19% loss)

19% of users drop off between Tutorial Start and Tutorial Complete. The current tutorial has 3 steps with text instructions. Playables with 1-step visual tutorials in the same genre show 8% average drop-off.
Current: 3 steps, text-based → 19% drop
Benchmark (casual platformers): 1 step, visual → 8% drop
Estimated impact: +5,800 users reaching game start per month
💡 Reduce tutorial to 1 visual step showing tap-to-jump gesture.
CRITICAL

"Satisfaction Trap" after Win (20% loss)

38% of users win the game, but only 18% click CTA. Users who WIN feel satisfied and don't need to install. This is the "Satisfaction Trap" — the playable is too complete an experience.
Win → CTA Click: only 47% conversion
Lose → CTA Click: 72% conversion (losers WANT to continue)
Optimal win rate for casual platformers: 55–65%
💡 Increase difficulty so win rate drops to ~60%. Add "Level 2 awaits!" teaser after win.
WARNING

CTA Text Underperformance

"Download Now" CTA performs 23% below industry benchmark for casual games. Action-oriented CTAs ("Continue Playing", "Play Full Game") consistently outperform download-focused CTAs in playable ads.
💡 Change CTA to "Continue Your Adventure →"
WARNING

Creative Fatigue Detected

IPM has declined 44% over 30 days (16.0 → 8.9). This matches typical creative fatigue patterns. Refresh cycle needed every 2–3 weeks for this genre.
💡 Generate 3 visual variants with different themes/backgrounds.

Geo Performance Variation
